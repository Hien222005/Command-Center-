# Command Center

A personal life-OS web app built as a single HTML file to track goals, habits, health, and projects in one place.

🔗 **Live demo:** https://dream-command-center.netlify.app

## Features

- **Score** — daily self-rating across multiple life areas
- **Calendar** — schedule view and event tracking
- **Health** — nutrition logging (calories, protein, carbs, fat) and workout tracking
- **Projects** — task and milestone management
- **Weekly Dashboard** — aggregated weekly view and trends
- **Settings** — customization options and data management

## Tech Stack

- HTML, CSS, JavaScript (vanilla, single-file app)
- Chart.js for data visualization
- localStorage for client-side persistence (key prefix: `cc7_`)
- jsdom for testing

## Run Locally

Open `index.html` in any modern browser. No build step, no dependencies to install.
